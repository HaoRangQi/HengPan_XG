# 平台期扫描系统

> 版本：`1.0.0` · 作者：熊猫吃竹子 · 本地部署

面向 A 股和加密永续市场的本地行情管理、横盘形态扫描与平台期研究工具。系统由 Vue 3 前端和 FastAPI 后端组成，行情写入本机 SQLite 数据库，扫描、结果筛选、K 线查看、历史记录和案例管理都在浏览器工作台内完成。

> 本项目仅用于数据分析、技术研究和学习，不构成任何投资建议。投资有风险，交易需谨慎。

## 主要能力

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 横盘-A | `#/` | 扫描 A 股末端锚定箱体，支持固定、末端振幅和容刺箱体规则 |
| 横盘-U | `#/platform` | 使用本地加密 1 小时线扫描横盘结构 |
| 平台-A | `#/crypto-a` | A 股多窗口平台期扫描，默认读取本地 60 分钟行情 |
| 平台-U | `#/crypto-u` | 使用本地加密行情进行多窗口平台期扫描 |
| 旧版 | `#/legacy` | 保留早期联网扫描入口，用于结果对照 |
| 数据 | `#/data` | 同步、查询、补拉、清理和检查 A 股及加密行情 |
| 接口 | `#/api-docs` | 在系统内查看后端 API；FastAPI 原始文档位于 `/docs` |
| AI | `#/ai` | 预留功能，当前施工中 |
| 关于 | `#/about` | 系统说明、操作指南和版本信息 |

其他能力包括扫描进度与停止、扫描历史、结果筛选与分页、K 线图、案例管理、深浅主题和参数说明。

## 本地启动

### 1. 环境要求

- Python `3.11` 或 `3.12`
- Node.js `20` 或更高版本
- npm `10` 或更高版本
- Git
- 可访问 Baostock 的 TCP `10030` 端口；同步加密行情时还需能访问 Binance 公共接口

系统只使用公开行情接口，不需要 Baostock 账号、Binance API Key 或其他密钥。

### 2. 获取代码

```bash
git clone --branch develop --single-branch https://github.com/HaoRangQi/HengPan_XG.git
cd HengPan_XG
```

如果代码已经在本机，直接进入项目根目录即可。后续命令都在项目根目录执行。

### 3. 安装后端依赖

macOS / Linux：

```bash
python3 -m venv api/.venv
api/.venv/bin/python -m pip install --upgrade pip
api/.venv/bin/python -m pip install -r api/requirements.txt
```

Windows PowerShell：

```powershell
py -3.11 -m venv api/.venv
api/.venv/Scripts/python.exe -m pip install --upgrade pip
api/.venv/Scripts/python.exe -m pip install -r api/requirements.txt
```

### 4. 安装前端依赖

```bash
npm ci
```

### 5. 启动后端

打开第一个终端，在项目根目录执行：

```bash
api/.venv/bin/python -m uvicorn api.index:app --host 127.0.0.1 --port 18001
```

Windows PowerShell 使用：

```powershell
api/.venv/Scripts/python.exe -m uvicorn api.index:app --host 127.0.0.1 --port 18001
```

看到 Uvicorn 启动日志后，可检查：

- 健康检查：<http://127.0.0.1:18001/>
- FastAPI 文档：<http://127.0.0.1:18001/docs>

健康检查应返回类似内容：

```json
{"status":"ok","message":"Stock Platform Scanner API is running","version":"1.0.0"}
```

### 6. 启动前端

保持后端终端运行，再打开第二个终端：

```bash
npm run dev
```

浏览器打开：<http://127.0.0.1:15173>

Vite 会把所有 `/api` 请求代理到 `http://127.0.0.1:18001`。不建议直接双击 `index.html`，否则前端代理和部分模块不会正常工作。

## 首次使用

### 数据库需要自己创建吗？

不需要。数据库文件、数据表和索引由后端自动创建，用户不需要安装 SQLite，也不需要执行 SQL。

但 Git 仓库不会附带行情数据库。第一次使用时，需要在页面中同步行情：

1. 打开“数据”。
2. 选择“A 股行情”或“加密货币”。
3. 保持“60 分钟”周期。
4. 选择需要的板块或类别。
5. 日期留空表示按本地进度增量同步。
6. 点击“开始同步”。

同步后会自动生成：

- `api/data/market.db`：A 股本地行情库
- `api/data/crypto.db`：加密货币本地行情库

`api/data/` 是本地运行目录，已被 Git 忽略。更新代码或重新安装前端依赖不会删除行情库。需要迁移机器时，请单独备份这个目录。

### 推荐操作顺序

1. 在“数据”页同步行情，确认卡片显示股票或交易对数量以及最新日期。
2. 进入“横盘-A / 横盘-U”设置箱体规则并运行横盘扫描。
3. 进入“平台-A / 平台-U”设置窗口和阈值并运行平台扫描。
4. 在结果页查看 K 线、筛选结果，或把典型标的加入案例管理。
5. 后续每天回到“数据”页再次点击同步，即可从本地进度继续增量更新。

扫描不会替代数据同步。使用本地来源的页面只读取 SQLite，不会在扫描过程中临时联网补数据。

## 数据源说明

### Baostock · A 股

- 当前客户端要求：`baostock>=0.9.4`
- 本地数据：60 分钟线，默认保留最近 60 天
- 默认板块：沪市主板、深市主板、创业板；科创板默认关闭
- IP 日请求上限：5 万次
- 限制时长：本年累计限制次数 × 6 小时
- Baostock 使用独立 TCP 协议和 `10030` 端口，不经过普通 HTTP 代理

首次全市场同步需要较长时间。同步支持停止和断点续传，已经写入的数据会保留；再次启动时，已是最新的股票不会重复请求。

### Binance 永续 · 加密

- 使用公开 REST 接口，不需要 API Key
- 本地数据：1 小时线，默认保留最近 60 天，即约 1440 根
- 类别：加密永续、TradFi 永续
- 最后一根尚未结束的 K 线会自动排除

如果页面提示 HTTP `451`，说明当前网络出口位于 Binance 受限地区，需要切换到可访问的网络节点后再同步。HTTP `418` 或 `429` 表示当前 IP 被临时封禁或限速，应停止重试并等待恢复。

## 常见问题

### 页面提示“无法连接后端服务”

确认后端终端没有退出，并访问 <http://127.0.0.1:18001/>。如果这里打不开，重新执行后端启动命令；如果能打开，检查前端使用的 `VITE_API_URL` 是否正确。

### Baostock 长时间没有响应

先在“数据 → 数据源”查看连通状态。代理软件的 TUN 模式可能截获 Baostock 的 TCP 连接，建议为 `baostock.com` 设置直连规则。不要反复并发重试，否则可能触发年度累计限制。

### 提示“用户未登录”或“黑名单用户”

“用户未登录”通常是 Baostock TCP 连接中断，系统会自动重新登录并重试。“黑名单用户”表示服务端已限制当前出口，应停止同步并等待解封；恢复后再次点击同步即可续传。

### 端口已被占用

不要同时启动多个后端或前端实例。可以关闭旧进程，也可以按“端口与配置”一节改用其他端口。

### 数据同步成功，但扫描没有结果

先检查所选市场、周期和数据日期是否匹配。横盘和平台扫描都有严格的窗口、振幅、缺口和阈值条件，没有结果不等于同步失败；可先缩短窗口或放宽阈值进行验证。

## 长时间运行与数据可靠性

扫描进度只传轻量结果，K 线在打开图表时读取。已完成并成功保存历史的任务缓存默认保留一小时、最多八个；同一后端最多八个活动任务。未保存的结果不会被普通清理删除，保存失败时可在扫描页重试。后端重启后，中断任务会恢复为“已中断”，已缓存候选仍可查看；它们不代表完整扫描。

案例现在存于 `api/data/cases.db`。首次访问自动备份旧 `cases/` 至 `api/data/cases-legacy-backup-initial`，校验后事务导入。旧文件保持不变；损坏数据会明确报错，不静默丢弃。备份项目数据时应保留整个 `api/data/`，包括保存失败任务的 `task-cache/`。不要把删除整个 task-cache 作为释放内存的操作。

窗口参数在界面中以 K 线“根数”为单位，`decline_period_days` 单独表示实际经过的日历天。旧历史会提示旧参数口径，重扫使用版本2。ST 状态缺失时显示未知，不推断为普通股票；同步行情时补齐本地日期对应的日线状态。

结果超过400条时完整保留，通过分页展示；停止的扫描只包含停止前已缓存的部分。扫描截止时间来自所选本地行情的已收盘时点，并不表示行情已经更新到现实当前时刻。
