# 横盘多模式与容刺箱体规格简述

## 目标

横盘-A 页面用一个顶层下拉框选择横盘算法，每种算法使用独立规则编辑组件。新增“容刺箱体”：在最近一段 K 线中用实体中心价寻找主体箱体，允许少量实体刺破，同时排除连续脱离箱体的走势。

## 已确认规则

- 模式名称：`末端定高`、`末端振幅`、`容刺箱体`。
- 容刺箱体默认参数：回看 80 根、箱体宽度上限 4%、允许实体刺破 4 根、允许连续实体刺破 1 根。
- 实体中心价定义为 `(open + close) / 2`，影线不参与主体箱体定位。
- 主体箱体是在价格轴上宽度不超过上限、覆盖实体中心价数量最多的区间。
- 箱体确定后，开盘价或收盘价越轨记为实体刺破；仅最高价或最低价越轨只作为影线越界指标展示，不导致容刺模式淘汰。
- 实体刺破总数超过上限，或连续实体刺破超过上限，判定失败。

## 兼容边界

- `fixed` 和 `amplitude` 的请求、计算、历史快照和导入文件保持原语义。
- 后端仍允许旧客户端提交多种 `box_type` 混合规则；新页面只为当前选择的模式创建新规则。
- 旧历史缺少新增字段时使用后端默认值；历史和导入结果仍可展示。
- 数据源、扫描周期、股票池、任务、历史、图表和旧版页面不在本次改造范围内。

## 验收

1. 顶层下拉切换三种模式，切换后挂载对应独立规则组件，并分别保留本次页面会话内的未提交参数。
2. 容刺算法覆盖正常横盘、允许刺数、连续两刺失败、长影线不影响定箱、大实体穿轨失败、边界相等和数据不足。
3. API 能接收 `box_type=tolerant`，判重只使用该模式有效字段。
4. 旧后端算法测试、前端测试及构建通过。
