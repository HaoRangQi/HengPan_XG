# 布林初始中点复核与连续扩展 - Reflection

## 结果

用户确认的三步规则已实现。初始 B 根整体和左右半段使用同一矩形误差公式，中点只检查一次；起点逐根前移时仅与固定末端比较，首次失败保留上一次起点。偶数长度取靠左中点。

## 证据与范围

- 旧实现的布林专项出现 10 个预期断言失败，双市场集成另有 3 个预期失败子场景。
- 修正后布林专项 30 项、后端完整 305 项、前端完整 90 项均通过；生产构建通过；git diff --check 通过。
- 新测试覆盖初始不合格不能被更长区间挽救、左右半段任一失败淘汰、首次扩展失败仍保留 B 根、后续坏点截断、扩展时不再复核中点、奇偶长度、中点零箱高、A/U 入选统计、最终区间均值与历史往返。
- 本轮改动相对于接手快照为 7 个源码/测试文件；未改原先的大图数量与布林开关。
- 非目标：不重算旧历史、不新增中点绘图、不增加步长选项。

## 架构与复杂度

- Architecture Alignment：aligned。共享算法唯一 owner 仍是 api/hengpan/boll_box.py；A/U 调用链、请求参数、返回 schema 和图表几何保持兼容。
- 核心文件 114 → 123 行，抽取 6 行模块内矩形误差 helper，整体、两半、扩展复用。旧全范围搜索循环删除，没有保留旧算法分支。
- 两份超过 1500 行的 Vue 页面仅替换说明并复用现有 BOX_MODES 文案 owner，没有新增状态或流程。复杂度治理建议：本轮无需拆分页面。
- Repair Track：修正初始检查和延伸规则；Retirement Track：最长到最短、失败后继续寻找的旧路径已删除。旧历史几何展示因兼容既有数据继续保留，不参与新算法。
- ADR Action：skip，采用本实施计划、代码注释和回归测试记录已确认规则。算法选择容易逆转，不满足 ADR Creation Gate 的全部条件；没有新增架构 owner、schema 或依赖。
- Baseline Sync：架构归属保持不变；当前行为说明已同步 ruleModes.js、双扫描页和 API 描述，无独立旧架构快照需要重写。

## 限制

一次中点复核仍为取样检查，不能证明区间所有位置都没有大幅波动；这是本轮明确接受的边界。旧历史不会自动获得新规则保证。构建保留原有大 bundle 与 Browserslist 数据过旧提示。

信心：A（算法及共享扫描路径有直接回归证据）；本轮未新增 UI 控件，因此以完整前端测试、构建和 Vite 资源读回验证文案更新。
